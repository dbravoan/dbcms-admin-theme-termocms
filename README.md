# termoCMS

Apariencia administrativa de Termosalud para `dbravoan/dbcms-core:~0.0.1`.
Posee su identidad, logos locales, paleta clara y presentaciones. El kit compartido
de controles, permisos y flujos pertenece a core.

```bash
composer require dbravoan/dbcms-admin-theme-termocms:~0.0.1
```

Selecciona `termocms` en la configuración del backoffice o al crear la aplicación
con el instalador. Core incluye un admin `dbcms` operativo sin este paquete.
La marca Termosalud y sus recursos permanecen exclusivamente en este repositorio.

El perfil predeterminado prueba branding, login, dashboard, errores, logos y
superficies legibles con core. La presentación opcional de Shop se verifica con
ese módulo real en un perfil independiente; no lo instala el perfil base.
